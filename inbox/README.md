# איפה לשים את החדשות

לכל ריצה יוצרים תיקייה עם התאריך והשעה של הריצה, ובתוכה קובץ טקסט:

```
inbox/globalnews/2026-10-23_0800/news.txt
inbox/globalnews/2026-10-23_1300/news.txt
inbox/globalnews/2026-10-23_1900/news.txt
```

- התאריך לפי שעון ישראל.
- השעה היא תמיד אחת משלוש: 0800, 1300, 1900.
- כדאי לשים את הקובץ עד חצי שעה לפני הריצה.
- אם אין קובץ, הריצה מדלגת על העמוד ולא מפרסמת כלום.
